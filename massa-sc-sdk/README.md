# massa-sc-sdk

Rust SDK for [Massa](https://massa.net) and [C-Layer](https://github.com/massalabs/c-layer)
smart contracts: typed host ABI, `Args` serialization compatible with
`massa-web3`, storage / context / coins / calls / deferred calls helpers,
`#[export]` entry points, and an in-memory mock VM for `cargo test`.

See the [repository README](https://github.com/massalabs/massa-rust-sc-sdk)
and the crate documentation (`cargo doc --open`).
